A free, no-backend website for **Pa Hawa Travel & Tours** — flight tickets, Umrah & Hajj packages, visa assistance, and hotel bookings.

Plain HTML/CSS/JS. No build tools, no paid software. Open `index.html` in a browser to preview.

## How to put this online for free

**Netlify Drop (easiest):** go to https://app.netlify.com/drop and drag the `pa-hawa-travel` folder in — instant live URL.

**GitHub Pages:** upload this folder to a GitHub repo, then Settings → Pages → deploy from the `main` branch. Live at `yourusername.github.io/repo-name`.

**Cloudflare Pages:** connect the repo at https://pages.cloudflare.com for a free `*.pages.dev` URL.

Any of these can later be pointed to a real domain (e.g. `pahawatravel.com`, ~$10–15/year) once you buy one.

## Editing without coding

Every page is a plain `.html` text file — open in Notepad or any text editor and edit the visible text directly (prices, phone numbers, routes are all plain readable text).
